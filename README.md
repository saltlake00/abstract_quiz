# 추상화 그림맞추기 온라인 (Abstract Art Quiz Online)

도형(삼각형)이 하나씩 쌓이며 점진적으로 드러나는 추상화 그림을 모든 참가자가 동시에 보면서 실시간 채팅으로 정답을 맞히는 온라인 멀티플레이 웹 게임입니다.

## 주요 기능
* **모두가 같은 화면 공유**: 방에 입장한 모든 플레이어가 실시간으로 그려지는 260개 도형 추상화 캔버스, 타이머 및 단계별 힌트, 실시간 채팅창, 점수판을 한 화면에서 함께 봅니다.
* **방 생성 및 비밀번호 잠금**: 누구나 방을 생성할 수 있으며, 선택적으로 비밀번호를 설정하여 허가된 참가자만 입장하도록 제한할 수 있습니다.
* **초대 링크 공유**: 상단 `초대 링크 복사` 버튼을 누르면 방 코드가 포함된 주소가 복사되어 친구들이 클릭 한 번으로 입장 화면에 접근할 수 있습니다.
* **무료 온라인 실시간 연동 (3중 하이브리드)**:
  1. **WebRTC (PeerJS 무료 클라우드)**: 회원가입이나 키 발급 없이 다른 네트워크 및 기기 간 실시간 연결
  2. **BroadcastChannel**: 동일 PC 내 여러 브라우저 탭 간 지연 없는 즉시 동기화 (항상 병행 작동)
  3. **Firebase Realtime Database (선택)**: 상단 `연동 설정`에서 데이터베이스 URL 입력 시 연동 지원
* **초기 15문항 수록**: 명화 5선(모나리자, 별이 빛나는 밤, 진주 귀걸이를 한 소녀, 절규, 해바라기), 게임 캐릭터 5선(피카츄, 마리오, 커비, 크리퍼, 티모), 애니 캐릭터 5선(도라에몽, 짱구, 아냐 포저, 카마도 탄지로, 토토로)

## 폴더 구조
* `primary_data/` : 원본 참조 이미지 데이터
* `secondary_data/` : 다중 스케일 오차 최소화 알고리즘으로 생성된 문항별 추상화 SVG (`svg_quiz_` 접두사)
* `intermediate_results/` : 도형 수에 따른 RMSE 수렴 측정치 및 엔진 검증 결과 CSV (`utf-8-sig`)
* `visualizations/` : 14문항 추상화 생성 결과 비교 이미지
* `interim_reports/` : 분석 방법론, 가정 검증, 한계 및 결과를 기록한 중간 보고서
* `scripts/` : 데이터셋 생성(`01_build_quiz_dataset.py`) 및 엔진 검증(`02_verify_quiz_engine.py`) 스크립트
* `data/` : 웹 클라이언트용 문제 데이터 번들(`questions.js`)
* `js/` : 규칙 엔진(`engine.js`), 네트워크 및 비밀번호 인증(`net.js`), 화면 제어(`app.js`)

## 로컬 실행 방법
정적 파일 서버를 띄워 브라우저에서 바로 실행할 수 있습니다.
```powershell
python -m http.server 8795
```
브라우저에서 `http://localhost:8795`에 접속합니다.
