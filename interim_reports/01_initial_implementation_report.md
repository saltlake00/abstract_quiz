# 중간 보고서 01: 추상화 그림맞추기 온라인 설계, 도형 분해 검증 및 멀티플레이 구현

## 1. 맥락 및 목적
기존 위키 기획 문서에서 구상했던 단계적 도형 공개 기반 그림 맞추기 게임을 독립된 웹 애플리케이션 프로젝트로 설계하고 구현했습니다. 모든 참가자가 동일한 화면(추상화 캔버스, 실시간 채팅, 점수판)을 공유하며, 방 생성과 비밀번호 설정을 통해 허가된 인원끼리 플레이할 수 있도록 구성했습니다.

## 2. 명시적 가정 및 방법 선택의 타당성

### 2.1 다중 스케일 삼각형 근사 (Primitive Decomposition)
* **가정**: 목표 이미지를 $N = 260$개의 반투명 삼각형($\alpha = 0.54$)으로 근사할 때, 초반에는 반경이 큰 삼각형($R \in [38, 95]$ px)으로 색면을 분할하고 후반에는 잔차 오차(Residual Error)가 높은 픽셀 주변에 작은 삼각형($R \in [4, 24]$ px)을 배치하면, 도형 개수에 따라 추상화에서 구상화로 전환되는 시각적 단계가 형성됩니다.
* **방법 선택의 타당성**: 단일 스케일 무작위 탐색은 세밀한 이목구비(피카츄의 뺨, 진주 귀걸이, 아냐의 눈동자 등)를 복원하는 데 수천 개의 도형이 필요하지만, 오차 확률 분포 기반의 다중 스케일 욕심쟁이(Greedy Hill Climbing) 탐색을 사용하면 260개 도형만으로도 모바일 데이터 전송량(문항당 약 15~22KB)을 낮추면서 특징점을 선명하게 복원할 수 있습니다.
* **검증 결과**: `scripts/01_build_quiz_dataset.py` 실행을 통해 도출된 `intermediate_results/rmse_convergence.csv`에서 15개 전 문항의 평균 RMSE가 초기 배경 상태($k=0$) 약 $69.2$에서 $k=25$ 시점 $45.8$, $k=100$ 시점 $32.7$, $k=260$ 시점 $24.0$으로 단조 감소함을 확인했습니다. 시각적 결과물은 `visualizations/quiz_14_primitive_results.png` 및 `secondary_data/` 내 개별 SVG에 저장되어 있습니다.

### 2.2 비선형 공개 곡선 및 점수 체계
* **가정**: 도형이 일정한 속도로 추가되면 초반 큰 도형이 순식간에 지나가 추상화 추론 구간이 너무 짧아집니다.
* **방법**: 경과 시간 비율 $(t/T)$에 지수 $\gamma = 1.85$를 적용한 $k(t) = \lfloor N \cdot (t/T)^{1.85} \rfloor$ 곡선을 적용했습니다. 30초 기준 10초 시점에 34개, 20초 시점에 122개, 30초 시점에 260개가 공개되어 초반 추론 재미와 후반 힌트 구간이 균형을 이룹니다.

### 2.3 무료 온라인 통신 구조 및 비밀번호 인증
* **방법 선택**: 별도 회원가입이나 유료 서버 없이 즉시 동작하도록 호스트 권위(Authoritative Host) 구조의 WebRTC(PeerJS 무료 클라우드)와 동일 기기 다중 탭용 `BroadcastChannel`을 동시 구동하고, 선택적으로 Firebase Realtime Database URL을 입력해 연동할 수 있도록 `js/net.js`를 구현했습니다.
* **비밀번호 보호 검증**: 방 생성 시 설정한 비밀번호를 방 코드와 결합하여 64비트 해시(`js/engine.js`의 `hashRoomPassword`)로 변환하고, 게스트 입장 요청(`JOIN_REQ`) 시 호스트가 해시 일치 여부를 검증하여 승인(`AUTH_OK`) 또는 거부(`AUTH_FAIL`)하도록 구현했습니다.
* **자동화 테스트 검증**: `scripts/02_verify_quiz_engine.py`를 통해 문법 검사 4건과 핵심 규칙 단위 시험 11건(총 15건)이 모두 통과함을 확인하고 `intermediate_results/engine_verification_results.csv`에 기록했습니다.

## 3. 한계점 및 향후 확장 과제
1. **호스트 브라우저 의존성**: 기본 무료 WebRTC 모드에서는 방장(호스트)의 브라우저가 방 상태를 관리하므로 방장 탭이 완전히 닫히면 방이 종료됩니다. 장시간 안정적인 방 유지를 원할 경우 상단 연동 설정에서 무료 Firebase Realtime Database URL을 연결할 수 있습니다.
2. **문제 풀 확장**: 현재 기본 세트는 명화 5선, 게임 5선, 애니 5선 총 15문항이며, `scripts/01_build_quiz_dataset.py`에 원본 이미지를 추가하여 손쉽게 문항 수를 확장할 수 있습니다.
