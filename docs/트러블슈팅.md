# 추상화 그림맞추기 온라인 트러블슈팅

## T1. 배포 후 새로고침해도 닉네임이 랜덤으로 바뀌지 않는 현상 (2026-10-16)
* **증상**: 랜덤 닉네임 생성 기능을 배포한 뒤 페이지를 새로고침해도 이전 화면(빈칸 또는 고정된 닉네임)이 그대로 유지됨.
* **원인**:
  1. `js/app.js`의 `init()`에서 `sessionStorage.getItem("aq_tab_nick")`에 최초 닉네임을 저장해 두고 재사용하도록 작성하여, 같은 탭에서 새로고침(F5)을 해도 세션 스토리지 값이 그대로 복원되어 새 랜덤 닉네임이 뽑히지 않았음.
  2. GitHub Pages의 기본 `Cache-Control: max-age=600` 헤더로 인해 `<script src="js/engine.js">` 및 `<script src="js/app.js">`가 브라우저 캐시에서 10분간 이전 버전으로 로드됨.
* **해결**:
  1. `js/app.js`의 `init()`에서 `sessionStorage` 캐시를 제거하고 페이지 로드 및 새로고침마다 항상 `QuizEngine.generateRandomNickname()`을 새로 호출하도록 수정.
  2. `js/engine.js`의 랜덤 생성기를 **[앞 상황 수식어 25종] + [행동 수식어 30종] + [명사 62종(화가 12, 야채 22, 동물 28)]**의 다중 랜덤 조합(약 4만 7천 가지 경우의 수)으로 확장.
  3. `index.html`에서 로컬 스크립트 4종(`data/questions.js`, `js/engine.js`, `js/net.js`, `js/app.js`)을 `Date.now()` 쿼리 파라미터와 함께 불러오도록 변경하여 캐시 문제를 근본적으로 차단.
* **캡처**: 없음 — 텍스트 증거: `02_verify_quiz_engine.py` 실행 결과 `random_nickname_format` 통과 및 로컬/원격 스크립트 쿼리 적용 확인.
