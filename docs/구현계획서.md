# 추상화 그림맞추기 온라인 (Abstract Art Quiz Online) 1차 구현 및 아키텍처 명세서

## 1. 개요 및 목적
도형(삼각형 및 다각형)이 하나씩 쌓이며 점진적으로 드러나는 추상화 그림을 모든 참가자가 동시에 보면서 실시간 채팅으로 정답을 맞히는 온라인 멀티플레이 웹 게임입니다.
* **핵심 경험**: 초반에는 거친 색면 추상화처럼 보이다가 도형이 쌓일수록 윤곽이 드러나며, 참가자들의 오답 채팅이 실시간으로 공유되고 먼저 알아본 사람이 고득점을 획득합니다.
* **화면 원칙**: 별도의 진행자 전용 화면 분리 없이 **접속한 모든 플레이어가 동일한 화면(추상화 캔버스 + 타이머 및 힌트 + 실시간 채팅 + 점수판)**을 함께 봅니다.
* **방 관리 및 보안**: 누구나 **방을 생성**할 수 있으며, **방 비밀번호(선택)**를 설정하여 허가된 친구들만 입장할 수 있습니다. 방 코드와 초대 링크는 원클릭으로 클립보드에 복사할 수 있습니다.
* **다중 수식어 랜덤 닉네임**: 접속 및 새로고침마다 `[상황 수식어 25종] + [행동 수식어 30종] + [화가·야채·동물 명사 62종]`을 무작위로 조합한 기본 닉네임을 자동 생성하여 입력 편의를 높였습니다.

## 2. 무료 온라인 실시간 연동 아키텍처 검증 및 선택
정적 웹 호스팅(GitHub Pages) 환경에서 백엔드 서버 비용 없이 운영 가능한 4중 하이브리드 실시간 통신 기술을 결합하여 구현했습니다.

1. **MQTT over WSS 실시간 웹소켓 브로커 (`wss://broker.emqx.io:8084/mqtt`, 기본 탑재)**
   * **가정 및 검증**: 모바일 LTE 및 5G 대칭형 NAT(CGNAT) 환경이나 숙소 공유기의 기기 간 격리(AP Isolation) 환경에서는 순수 P2P 연결이 차단될 수 있습니다. 웹소켓(443/8084 포트) 기반의 공개 MQTT 브로커를 병행하면 방화벽 제약 없이 100% 메시지 도달이 보장됩니다.
2. **WebRTC P2P + PeerJS 무료 클라우드 브로커 (기본 탑재)**
   * **용도**: 8명 내외의 소규모 방에서 방 생성자(호스트)의 브라우저가 권위 서버(Authoritative Host) 역할을 수행하고 참가자들이 호스트에 성형(Star) 토폴로지로 직접 연결됩니다.
3. **동일 기기 다중 탭 동기화 (`BroadcastChannel` 자동 병행)**
   * **용도**: 로컬 PC 한 대에서 여러 브라우저 탭을 띄워 즉시 멀티플레이를 시험하거나 오프라인 환경에서 테스트할 때 지연 시간 0ms로 동작합니다.
4. **Firebase Realtime Database (선택적 확장 어댑터 내장)**
   * **용도**: 무료 Spark 요금제(동시 접속 100명, 저장 1GB 무료)를 사용하고자 할 때 상단 설정 창에 `databaseURL`만 입력하면 코드 수정 없이 중앙 DB 모드로 전환됩니다.
5. **패킷 중복 제거 (`_mid` 필터링)**
   * 여러 전송 채널이 동시에 열려 있어도 각 패킷에 부여된 고유 식별자(`_mid`)를 기준으로 최초 도착한 메시지 1회만 처리하여 중복 렌더링이나 중복 채점이 발생하지 않습니다.

## 3. 시스템 구조 및 폴더 체계
재현 가능한 데이터 생성 파이프라인과 웹 애플리케이션을 분리하여 다음과 같은 폴더 구조를 사용합니다.

* `primary_data/` : 원본 이미지 및 메타데이터(변경 불가능한 원시 데이터)
* `secondary_data/` : 전처리 및 추상화 도형 근사 알고리즘을 거쳐 생성된 SVG 및 JSON 파생 데이터(`svg_quiz_` 접두사 사용)
* `intermediate_results/` : 도형 개수 증가에 따른 오차(RMSE) 감소 측정치 및 수렴 분석 CSV 파일(`utf-8-sig` 인코딩)
* `visualizations/` : 도형 단계별 비교 시각화 이미지
* `interim_reports/` : 데이터 생성 검증, 알고리즘 타당성, 한계점 및 추가 기능 분석 결과를 기록한 중간 보고서
* `scripts/` : 두 자리 숫자로 시작하는 메인 파이프라인 스크립트(`01_build_quiz_dataset.py`, `02_verify_quiz_engine.py`)
* `pdfs/` : 관련 레퍼런스 문서 보관 폴더
* `data/` : 웹 클라이언트가 로드하는 최종 문제 번들(`questions.js`)
* `js/` : 클라이언트 모듈(`net.js` 네트워크 및 방 비밀번호 인증, `engine.js` 정답 판정 및 점수 계산, `app.js` UI 상태 관리)

## 4. 핵심 기능 명세 (1차 배포 기준)

### 4.1 방 생성 및 비밀번호 인증 흐름
1. **방 만들기 (호스트)**
   * 닉네임(자동 생성 또는 직접 수정), 방 코드(자동 생성 5자리 또는 직접 입력, 클립보드 복사 지원), **방 비밀번호(선택, 비워두면 공개방)**, 라운드 수(5 / 10 / 15), 문제 카테고리(전체 / 명화 / 게임 / 애니), 라운드 제한 시간(25초 / 30초 / 40초)을 설정합니다.
   * 비밀번호는 평문 노출을 막기 위해 클라이언트에서 방 코드 솔트(Salt)가 결합된 FNV1a 64비트 해시(`hashRoomPassword`)로 변환하여 입장 요청(`JOIN_REQ`) 시 호스트가 대조합니다.
2. **방 입장하기 (게스트)**
   * 방 코드를 입력하거나 초대 링크(`?room=코드`)로 접속합니다.
   * 호스트에게 입장 요청을 보내면, 비밀번호가 설정된 방일 경우 해시 일치 여부를 확인하며 불일치 시 입장 거부(`AUTH_FAIL`) 안내를 표시합니다.
   * 승인(`AUTH_OK`) 시 대기실 참가자 목록에 추가되고 기존 방 상태와 동기화됩니다.

### 4.2 추상화 단계 공개 수식 및 동기화
* 한 문제당 총 $N = 260$개의 삼각형(`<polygon>`)을 오차 감소 순으로 정렬해 보관합니다.
* 라운드 시작 후 경과 시간 $t \in [0, T]$에 대해 공개되는 도형 개수 $k(t)$는 비선형 거듭제곱 곡선을 따릅니다.
  $$k(t) = \min\left(N, \max\left(1, \left\lfloor N \cdot \left(\frac{t}{T}\right)^{1.85} \right\rfloor\right)\right)$$
* 초반에는 큰 색면 도형이 천천히 추가되어 추상화 느낌을 주고, 후반부로 갈수록 세부 묘사 도형이 빠르게 쌓입니다.
* 호스트가 라운드 시작 시 기준 경과 시간(`elapsedMs`)을 주기적으로 브로드캐스트하여 모든 참가자가 동일한 도형 단계를 봅니다.

### 4.3 정답 판정 및 점수 산정
* **한국어 IME 조합 보호**: 모바일 및 데스크톱 브라우저에서 한글 입력 중 엔터 키 입력 시 `event.isComposing`을 확인하여 마지막 글자가 잘리거나 두 번 전송되는 현상을 방지합니다.
* **정규화 비교**: 입력 문자열에서 공백과 특수문자를 제거하고 소문자로 변환하여 대표 정답 및 별칭(예: 영문명, 줄임말, 작가명 등) 목록과 대조합니다. 5글자 이상 긴 정답은 레벤슈타인 편집 거리 1 이내 오타 허용 옵션을 지원합니다.
* **점수 산정**:
  * 기본 점수: 맞힌 시점의 도형 공개 비율에 반비례하여 부여합니다.
    $$\text{Score}_{\text{base}} = \max\left(20, \text{round}\left(100 \cdot \left(1 - 0.8 \cdot \frac{k}{N}\right)\right)\right)$$
  * 선착순 보너스: 1등 $+30$점, 2등 $+15$점, 3등 $+5$점을 가산합니다.
  * 정답자의 채팅은 다른 사람에게 정답이 노출되지 않도록 `"🎉 [닉네임]님이 도형 k개에서 맞혔습니다! (+점수)"` 시스템 메시지로 변환되어 전송됩니다.

## 5. 초기 15문제 구성 (명화 5 · 게임 5 · 애니 5)
색상 대비와 실루엣 특징이 뚜렷하여 도형 30~80개 구간에서 추론의 재미가 발생하는 대표작 15선으로 구성했습니다.
1. **명화 (5선)**: 모나리자, 별이 빛나는 밤, 진주 귀걸이를 한 소녀, 절규, 해바라기
2. **게임 캐릭터 (5선)**: 피카츄, 마리오, 커비, 크리퍼(마인크래프트), 티모(리그 오브 레전드)
3. **애니 캐릭터 (5선)**: 도라에몽, 짱구, 아냐 포저(스파이 패밀리), 카마도 탄지로(귀멸의 칼날), 토토로(이웃집 토토로)
